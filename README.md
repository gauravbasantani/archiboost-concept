# Archiboost design concept (unofficial)

An unofficial design concept by Gaurav Basantani: one QA/QC ticket in the style of Archiboost's ticket view, where a corridor flag counts one room twice (once from the plan, once from the room schedule) and the right answer is Reject with reason.

Live page: https://gauravbasantani.github.io/archiboost-concept/

The project, firm, people, rooms and areas are made up. Code rules are simplified from the 2021 IBC; this is not code advice. Not affiliated with Archiboost.
